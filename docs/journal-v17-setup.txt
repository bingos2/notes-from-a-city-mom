My Baby's Little Days v17 | Tools 배포 준비본
======================================================
기존 v16과 공개 사이트는 수정하지 않았습니다. 이 패키지는 별도 브랜치에서 먼저 검증하세요.

포함 파일
- tools/my-babys-little-days/editor.html: 편집기, 미리보기, 글 잘림 검수,
  기기 내 직접 PDF 다운로드, 결제 후 복구 UI
- api/journal-checkout.js: 별도의 Vercel 결제·주문 기록 API. 기존 api/paypal 파일을
  덮어쓰지 않습니다. 예약된 가격은 서버에서 9.90 USD로 고정합니다.
- scripts/journal-order-backup.mjs: 운영자용 주문 CSV 백업

배포
1. 위 경로대로 기존 notes-from-a-city-mom 저장소에 추가합니다. Tools 목록 공개 링크는
   검증 전까지 바꾸지 않습니다. 새 편집기를 실제 서비스에 연결하기 전에 v16에서 만든
   편집 파일을 백업하세요. 같은 사이트에서 구버전과 새 버전을 동시에 편집하지 마세요.
2. Journal 전용 환경 설정 (Preview/Production 범위는 따로 지정):
   JOURNAL_EDITOR_URL = 동일 Vercel 환경의 HTTPS 편집기 주소. 실제 접속 URL과 같은 origin.
   JOURNAL_PAYPAL_MODE = sandbox
   PAYPAL_SANDBOX_CLIENT_ID / PAYPAL_SANDBOX_CLIENT_SECRET
     (현재 Production의 PAYPAL_CLIENT_ID / PAYPAL_CLIENT_SECRET_KEY는 sandbox에서만
      호환됩니다. Preview에 상속되지 않습니다. Sandbox 호스트 인증이 실패하면 결제 불가. 이 브랜치의 Preview에 Live 키를 넣지 마세요.)
   PAYPAL_SANDBOX_MERCHANT_ID = 선택; 설정하면 결제 수취인 검증에 사용.
   JOURNAL_REDIS_URL / JOURNAL_REDIS_TOKEN = HTTPS Upstash REST 주소와 쓰기 토큰.
     기존 UPSTASH_REDIS_REST_KV_REST_API_URL / ..._TOKEN이 있으면 자동 사용.
   JOURNAL_ADMIN_TOKEN = 최소 32자 고유 비밀값. CSV export에만 사용.
   Secret과 관리자 토큰은 Vercel의 비공개 환경변수로만 설정하세요. HTML·Git·채팅에 넣지 마세요.
3. 보호된 Preview에서 합성 데이터로 실제 PayPal Sandbox 구매:
   취소 → 같은 주문 재시도, 정상 결제 → PDF, 결제 성공 직후 네트워크 끊기 →
   Recover order로 재결제 없이 파일 받기, 여러 번 요청해도 결제 1건 확인.
   PayPal로 이동했다 돌아오는 브라우저에서 직접 파일을 내려받을 수 있는지
   실제 iPhone Safari/Android 및 데스크톱에서 확인하세요. 앱 내 브라우저에서
   미지원 시 주문에 사용한 기본 브라우저에서 열게 안내하세요.
4. 검증 후에만 Live:
   PAYPAL_LIVE_CLIENT_ID, PAYPAL_LIVE_CLIENT_SECRET, PAYPAL_LIVE_MERCHANT_ID
   JOURNAL_PAYPAL_MODE=live, JOURNAL_LIVE_ENABLED=true.
   sandbox/live 승인 링크·API 호스트·주문 기록은 분리됩니다.
   수취인이 한국 등록 판매 계정일 경우, 한국 국내 구매가 아닌 자격 있는 미국 대상
   구매자 기준으로 확인하세요. 실결제 검증은 실제로 돈이 움직입니다. 승인 범위가
   정해지기 전 실제 결제를 실행하거나 공개 Tools에 연결하지 마세요.

두 종류의 백업
- 고객: 구매하기 전에 해당 PDF와 편집 파일을 브라우저에 저장합니다.
  같은 브라우저에서 Recover order로 돌아와 재결제 없이 받을 수 있습니다.
  브라우저 데이터 삭제, 기기 변경, 시크릿 창 종료 시 사이트가 개인 글·사진을 갖고
  있지 않아 PDF를 복구할 수 없습니다. 기기 변경 전 PDF와 편집 파일을 별도 보관하세요.
  별도의 내보내기 파일은 다운로드 권한 자체를 옮기지는 않습니다.
- 운영자: 명령 실행 환경에 JOURNAL_CHECKOUT_URL과 JOURNAL_ADMIN_TOKEN을
  비밀 환경변수로 설정한 뒤 node scripts/journal-order-backup.mjs 를 실행하세요.
  결제 상태, PayPal 주문/거래 ID, 금액, 결제 시각, PDF 다운로드 요청 횟수/시각을
  CSV로 백업합니다. 고객 이름·이메일·사진·글·PDF는 주문 기록에 들어가지 않습니다.
  ‘다운로드 요청’은 버튼 동작을 뜻하고 기기 저장을 보증하지 않습니다.
  체크아웃 중 연결이 끊겨 주문이 CREATED로 남으면 PayPal에서 거래를 확인한 뒤
  구매자에게 기존 주문을 다시 확인하도록 안내하세요. 전체 주문 백업은 거래가 적은
  시간에 실행하고, 환불·분쟁·정산은 PayPal 기록과 대조하세요.

PDF
- 버튼으로 .pdf를 내려받으며 프린트 대화상자를 거치지 않습니다.
- 글과 사진은 브라우저에서 렌더링됩니다. 현재 PDF는 페이지 이미지 방식이라
  글 검색/복사와 스크린 리더용 PDF 텍스트가 제공되지 않습니다.
- sandbox, live 어디에도 가족 기록을 서버에 업로드하지 않습니다.
